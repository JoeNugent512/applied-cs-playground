# Team Explorer AI project rulebook

I am a beginner building a fictional, read-only Microsoft Power Apps Canvas
app named **Team Explorer** with Power Fx. Work beside me; do not use embedded
AI or require Copilot licensing.

1. Do not assume important app details. Ask when a missing detail would
   materially change the formula.
2. Use the exact data source, column, collection, variable, and control names I
   provide.
3. The data source is `TeamMembers`. The teaching columns are `ID`, `Name`,
   `JobTitle`, `Team`, `Education`, `Skills`, `Expertise`, `Tools`,
   `Certifications`, `Location`, `Email`, `Bio`, `AskMeAbout`, and
   `ProfileImage`.
4. `ID` is an autogenerated Number. All other local fixture fields are
   strings. `Team` is plain text and `ProfileImage` is plain multiline text
   containing a self-contained data:image/svg+xml image data URL. Do not change
   them to Choice, Hyperlink, Person, or Image without checking the real schema.
5. Multiline values use newline characters in the canonical List/export. The
   browser may split a value at `Char(10)` to render chips, but that does not
   change the stored column type.
6. Name the exact control property for every formula. Use these names when
   applicable: `galTeamMembers`, `txtSearch`, `drpTeam`,
   `varSelectedEmployee`, `scrTeamExplorer`, and `scrProfile`.
7. Prefer the smallest change. Do not rewrite working parts or add features
   that were not requested.
8. Diagnose before replacing code. Ask for Context, Code, Expected, Actual,
   selected record, variable state, and safe Data evidence.
9. Give one tiny test, one change, and a retest. Use
   **Observe → Hypothesize → Test → Learn**.
10. Read generated code before using it. Check the control names, field names,
    types, and property. Ask for an explanation of anything unfamiliar.
11. Keep a working version. Make one change, test it, and keep or revert it
    before changing another layer.
12. Treat screenshots as context for layout, galleries, forms, navigation,
    controls, and formula errors. Never include secrets, tenant URLs, or
    personal data.
13. Use English-locale commas in examples; tell me when my authoring locale
    requires semicolons.
14. Use `Copy(JSON(...))` only in a behavior property such as a button's
    `OnSelect`. If clipboard access is blocked, display the JSON in a
    multiline control for manual copying.
15. Do not add `Patch`, SubmitForm, server-write behavior, flows, Dataverse,
    custom APIs, live employee lookup, or real organizational data.

The human is the developer. AI can help move faster when the developer
understands the system well enough to explain, test, and debug it.
